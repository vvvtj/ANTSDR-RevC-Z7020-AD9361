# Contributing

Спасибо за улучшения документации и поддержку платы.

- Для hardware-фактов указывайте точную ревизию PCB и источник измерения.
- Для прошивок указывайте происхождение, хеш, лицензии и проверенный сценарий восстановления.
- Для программ указывайте ОС, версии и журнал воспроизведения.
- Не публикуйте секреты, ключи, уникальные данные чужих устройств, приватные дампы или материалы без прав распространения.
- Предлагайте изменения через Pull Request; одну самостоятельную задачу — в одном PR.
- Для ошибок прикладывайте безопасно очищенные логи и точные шаги воспроизведения.
