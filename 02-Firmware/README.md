# 02 · Firmware

## Структура

- `sources/` — проверенные исходники U-Boot, Linux, device tree, FPGA и компонентов сборки; ссылки на upstream и лицензии.
- `prebuilt/` — манифесты бинарных образов и инструкции. Крупные готовые файлы публикуются через GitHub Releases.
- `backups/` — процедуры создания локальных резервных копий, **без** частных данных конкретного устройства.
- `changelogs/` — история, совместимость, контрольные суммы.

Обнаружена строка версии `v0.39-1-g7bcc-dirty`, ядро Linux 6.1. Это **не** подтверждённый полный идентификатор комплекта исходников и FPGA-битстрима. **Проверенных публичных бинарных релизов пока нет**. Не прошивайте неизвестные образы.
