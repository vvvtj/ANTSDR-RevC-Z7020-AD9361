# Windows: SDRangel + ANTSDR

## Подготовка

- Windows 10/11, USB-адаптер устройства, исправное питание.
- SDRangel со включённой поддержкой PlutoSDR/libiio.
- Командная утилита `iio_info` (опционально, для диагностики).

## Диагностика

```powershell
Get-NetAdapter | Format-Table Name,Status,InterfaceDescription
ping 192.168.2.1
iio_info -u ip:192.168.2.1
```

IP `192.168.2.1` — **ранее наблюдавшаяся конфигурация**, а не гарантия для каждой платы и прошивки.

## SDRangel

Откройте Input devices, выберите PlutoSDR и проверьте связь с IIO. При доступной настройке User arguments задайте `uri=ip:192.168.2.1`. Запустите только RX-канал и убедитесь, что график обновляется. Для двух каналов используйте поддерживаемую MIMO-конфигурацию и отдельно проверьте маршрутизацию RX1/RX2.

## Если нет сигнала

1. Проверьте, что IIO видит устройство.
2. Проверьте правильный RX-вход, антенну и рабочий диапазон.
3. Снизьте частоту дискретизации или ширину полосы.
4. Убедитесь, что другие программы не удерживают IIO-контекст.
5. Сохраните журнал программы перед созданием Issue.

Передатчик TX не нужен для этих проверок.
